# Homebrew Tap for M-Series Video Converter

Install the Apple Silicon macOS app and its FFmpeg, ExifTool, and jq dependencies with:

```bash
brew tap RealHaltewunsch/tap
brew install --cask m-series-video-converter
```

Upgrade or uninstall it with:

```bash
brew upgrade --cask m-series-video-converter
brew uninstall --cask m-series-video-converter
```

The application source and release notes live in the [main repository](https://github.com/RealHaltewunsch/mseries-video-converter).
